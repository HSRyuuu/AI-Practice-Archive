# Skills

AI 코딩 어시스턴트에서 사용하는 커스텀 스킬 모음. 각 스킬은 특정 도메인의 베스트 프랙티스와 가이드라인을 제공한다.

## 스킬 목록

| 스킬명 | 사용 시점 |
|--------|----------|
| **api-design** | REST API 설계 시 (리소스 네이밍, 상태 코드, 페이지네이션, 에러 응답, 버전 관리 등) |
| **article-writing** | 아티클, 가이드, 블로그 포스트, 튜토리얼 등 장문 콘텐츠 작성 시 |
| **fastapi-guide** | FastAPI 엔드포인트 작성, Pydantic 모델 설계, DB 세션 관리, 프로덕션 배포 설정 시 |
| **frontend-design** | 웹 컴포넌트, 페이지, 애플리케이션 등 프론트엔드 UI 구현 시 |
| **git-master** | Git 커밋 전략, 리베이스, 히스토리 관리 시 |
| **manage-skill** | 스킬 생성/업데이트/탐색 및 CLAUDE.md 관리 시 |
| **node-backend-patterns** | Node.js, Express, Next.js API 라우트, NestJS 백엔드 개발 시 |
| **springboot-java-standards** | Java 17+ 코딩 표준 및 Spring Boot 서비스 개발, JPA/QueryDSL 작업 시 |
| **test-sync-verifier** | 코드 변경 후 테스트 실패 검증 및 테스트 코드 수정 시 |
| **verify-implementation** | 기능 구현 후 통합 검증 보고서 생성, PR 전 최종 확인 시 |
