# Update README

등록된 README 파일의 목록 테이블을 실제 디렉토리 내용과 동기화한다.

## 관리 대상 README

| README 경로 | 감시 디렉토리 | 테이블 섹션명 | 항목 설명 소스 | 설명 추출 방식 |
|-------------|-------------|-------------|--------------|-------------|
| `/skills/README.md` | `/skills/` | 스킬 목록 | 각 하위 폴더의 `SKILL.md` 또는 `skill.md` | frontmatter `description` > "적용 시점"/"사용 시점" 섹션 > 본문 첫 단락 |
| `/skills-project-depends/README.md` | `/skills-project-depends/` | 등록된 스킬 그룹 | 각 하위 폴더의 `README.md` > 하위 폴더 내 `SKILL.md` 파일들 | 그룹 README 첫 단락 > 포함된 SKILL.md들의 description 종합 |

> 새 README를 관리 대상에 추가하려면 이 테이블에 행을 추가한다.

## 절차

### 1. 현재 상태 수집

- 위 테이블에서 대상 README와 감시 디렉토리를 확인한다.
- 감시 디렉토리의 하위 폴더 목록을 가져온다 (README.md 등 파일 제외).
- README의 해당 테이블 섹션에서 이미 등록된 항목명을 파싱한다.

### 2. 차이(diff) 도출

- **누락 항목**: 디렉토리에는 있지만 테이블에 없는 항목.
- **고아 항목**: 테이블에는 있지만 디렉토리에 없는 항목.
- 둘 다 없으면 "목록이 최신 상태입니다"라고 알리고 종료한다.

### 3. 누락 항목 설명 추출

각 누락 항목의 폴더에서 "설명 추출 방식" 열에 명시된 우선순위에 따라 설명을 추출한다.

추출한 설명을 한국어로, 기존 행과 비슷한 길이(한 줄, ~50자 이내)로 요약한다.

### 4. 테이블 업데이트

README의 기존 테이블 형식을 그대로 따른다.

- 누락 항목 행을 추가한다.
- 고아 항목 행을 제거한다.
- 전체 테이블을 항목명 기준 알파벳/가나다 오름차순으로 정렬한다.
- 테이블 헤더와 구분선은 수정하지 않는다.

### 5. 결과 보고

변경 내용을 사용자에게 요약한다:
- 추가된 항목 목록
- 제거된 항목 목록
