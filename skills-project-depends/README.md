# Skills - Project Depends

프로젝트에 의존적인 스킬들을 관리합니다. 각 프로젝트 루트의 `.claude/skills/`에 배치하여 사용합니다.

## 등록된 스킬 그룹

| 스킬 그룹 | 설명 | 사용법 |
|---|---|---|
| verify-project-conventions | 프로젝트의 convention 준수 여부를 검증하기 위한 스킬들을 생성하고, 통합 검증을 수행합니다. | 코드 작업 후 `/manage-skills`로 검증 스킬을 생성·갱신하고, 검증이 필요할 때 `/verify-implementation`을 실행하세요. |
