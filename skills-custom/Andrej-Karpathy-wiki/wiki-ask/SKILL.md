# Wiki 질문 답변

이 스킬은 Wiki에 축적된 지식을 기반으로 질문에 답변한다.
답변 과정에서 여러 소스를 교차 참조하며, 가치 있는 합성 답변은 wiki에 저장하여 지식을 누적한다.

## 수행 절차

### Step 0. 볼트 경로 확인 + 스키마 읽기

1. `~/.config/wiki/config.json`을 읽어 `wiki_root` 경로를 확인한다.
2. 파일이 없거나 `wiki_root`가 없으면 사용자에게 볼트 경로를 물어본 뒤 `~/.config/wiki/config.json`에 저장한다.
3. `{wiki_root}/CLAUDE.md`를 읽고 문서 타입, frontmatter 컨벤션, slug 규칙, 디렉토리 구조를 확인한다.
4. CLAUDE.md가 없으면 에러: **"CLAUDE.md가 없습니다. `/wiki-setup`을 먼저 실행하세요."**

### Step 1. 탐색 및 답변 합성

#### 1-1. 인덱스 탐색

`wiki/index.md`를 읽고 관련 서브 인덱스로 drill-down하여 문서를 파악한다.

- index.md에서 관련 hub 또는 concept을 찾아 문서 목록을 추린다.
- 관련 문서가 부족하면 qmd로 2차 검색한다: `qmd search "질문 키워드" 2>/dev/null`
- qmd가 없으면 `wiki/concepts/`, `wiki/sources/` 디렉토리를 직접 탐색한다.
- 필요시 `raw/` 디렉토리의 원본 소스도 참조한다.

#### 1-2. 관련 문서 읽기

관련성이 높은 문서를 선정하여 읽는다.

- 각 문서의 본문과 frontmatter를 확인한다.
- 문서 내 `[[wiki-link]]`를 따라가며 백링크 문서도 탐색한다.
- 탐색 범위는 질문의 복잡도에 따라 LLM이 판단한다.

#### 1-3. 답변 합성

탐색한 문서를 기반으로 답변을 작성한다.

- **인라인 위키링크 인용**: 답변 본문에서 정보의 출처를 `[[concepts/슬러그]]` 또는 `[[sources/슬러그]]` 형태로 인라인 표기한다.
- 여러 소스의 정보를 교차 분석하여 통합된 답변을 제공한다.
- wiki에 관련 문서가 없거나 부족하면 솔직하게 "현재 Wiki에는 이 주제에 대한 정보가 부족합니다"라고 안내한다.
- 답변 마지막에 참조한 문서 목록을 정리한다:

```markdown
**참조 문서:**
- [[concepts/문서1]] — 간단 설명
- [[sources/문서2]] — 간단 설명
```

### Step 2. 답변 저장 여부 확인

답변 완료 후 사용자에게 묻는다:

> "이 답변을 wiki에 저장할까요?"

#### 저장 기준

아래 조건을 **하나라도** 만족하면 저장을 **권장**한다:

| 조건 | 설명 |
|---|---|
| **다중 소스 합성** | 2개 이상의 문서를 교차 참조하여 새로운 통찰을 도출한 경우 |
| **비자명한 추론** | 단순 사실 조회가 아니라 분석/비교/종합이 포함된 경우 |
| **반복 질문 가능성** | 향후 동일하거나 유사한 질문이 예상되는 경우 |

아래 경우에는 저장을 **권장하지 않는다**:

| 조건 | 설명 |
|---|---|
| **단순 사실 조회** | 단일 문서에서 바로 찾을 수 있는 팩트 질문 |
| **일회성 질문** | 재활용 가능성이 낮은 맥락 특수적 질문 |

#### 저장 시 문서 생성

사용자가 저장을 승인하면 `wiki/concepts/{slug}.md`로 저장한다.

- **slug**: 질문 핵심 키워드로 kebab-case 생성 (CLAUDE.md 규칙 준수, 최대 60자)
- **type**: `answer`
- **frontmatter**:

```yaml
---
tags: [{핵심태그}, {자유태그}, ...]
type: answer
created_at: {ISO 8601 UTC}
updated_at: {ISO 8601 UTC}
---
```

- **본문 구조**:

```markdown
# {질문을 명사구로 변환한 제목}

## 질문

{원본 질문}

## 답변

{위키링크 인용이 포함된 합성 답변}

## 참조 문서

- [[concepts/문서1]] — 간단 설명
- [[sources/문서2]] — 간단 설명
```

- 저장 후 `wiki/index.md`에 문서를 추가한다.
- `wiki/log.md`에 로그를 append한다:

```markdown
## [{YYYY-MM-DD}] ask | {질문 50자}
- 참조: [[concepts/{slug1}]], [[sources/{slug2}]]
- 답변: [[concepts/{answer-slug}]]
```

### Step 3. Git 커밋

변경 사항이 있으면 커밋한다.

- 답변을 저장한 경우:

```bash
git add wiki/concepts/{slug}.md wiki/index.md wiki/log.md
git commit -m "wiki: ask '{질문 50자}'"
```

- 답변을 저장하지 않은 경우: 커밋하지 않는다.

### Step 4. (부수) qmd 인덱스 리빌드

wiki 문서가 추가/수정된 경우 검색 인덱스를 갱신한다.

```bash
qmd index rebuild 2>/dev/null || true
```

- qmd가 설치되어 있지 않으면 이 단계를 건너뛴다.
- 이 단계는 실패해도 전체 스킬 실행에 영향을 주지 않는다.
