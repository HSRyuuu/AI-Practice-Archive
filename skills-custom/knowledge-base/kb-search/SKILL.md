# KB Search — 검색/질문 답변

Knowledge Base에 축적된 지식을 기반으로 질문에 답변한다.

---

## Step 0. 볼트 경로 확인 + 스키마 로드

1. `~/.config/kb/config.json`을 읽어 `kb_root` 경로를 확인한다.
2. 파일이 없거나 `kb_root`가 없으면 사용자에게 볼트 경로를 물어본 뒤 저장한다.
3. `{kb_root}/SCHEMA.md`를 읽어 폴더 구조를 파악한다.
4. `{kb_root}/.claude/CLAUDE.md`를 읽어 컨벤션을 확인한다.
5. 없으면 에러: **"`/kb-setup`을 먼저 실행하세요."**

---

## Step 1. 검색 (5계층)

아래 순서로 관련 문서를 찾는다:

### 계층 1: frontmatter 필터

질문에서 키워드를 추출하고, `tags`/`group` frontmatter로 1차 필터링한다.

### 계층 2: 00_index_{Name}.md 한줄 요약

각 폴더의 `00_index_{Name}.md`를 읽어 한줄 요약에서 관련 문서를 식별한다. 루트 폴더 index부터 시작하여 하위 폴더로 drill-down한다.

### 계층 3: qmd 검색 (설치 시)

```bash
qmd search "{질문 키워드}" 2>/dev/null
```

qmd가 미설치면 이 계층을 건너뛴다.

### 계층 4: 위키링크 따라가기

발견된 문서 내의 `[[위키링크]]`를 따라가며 관련 문서를 추가 탐색한다.

### 계층 5: 본문 읽기

관련성이 높은 문서를 선정하여 본문을 읽고 답변을 합성한다.

---

## Step 2. 답변 합성

- 탐색한 문서를 기반으로 답변을 작성한다.
- **인라인 위키링크 인용**: 정보의 출처를 `[[경로/문서명]]` 형태로 본문에 표기한다.
- 여러 문서를 교차 참조하여 통합된 답변을 제공한다.
- KB에 관련 문서가 없거나 부족하면 솔직하게 안내한다:
  > "현재 KB에는 이 주제에 대한 정보가 부족합니다."

답변 마지막에 참조 문서 목록을 정리한다:

```markdown
**참조 문서:**
- [[경로/문서1]] — 간단 설명
- [[경로/문서2]] — 간단 설명
```

---

## 참고

- 이 스킬은 **읽기 전용**이다. 문서를 수정하지 않는다.
- Git 커밋 없음.
- qmd 인덱스 리빌드 없음.
